# General Skill — Format & Playbook (editorial newsletters)

> **⚠️ Updated Aug 5:** this is the editorial news-card format — ONE of four types, not universal (see `newsletter-types.md`). Story/StoryBrand (Local Affiliate Pro, Main Street), independent-news (The Referral Channel), and Donald-Miller storytelling (The Open Source) are shaped differently — see each newsletter's own skill. **Niche/industry newsletters use a card format but WITHOUT the native card / offer / bottom CTA (pure education).**

The structure for editorial newsletters that use the news-card format. (Each newsletter's own skill in `../newsletters/` is the final word on its format.)

## Issue structure
Masthead (brand + tagline + issue no. + date) → byline → intro (one POV thesis line) → "In this issue" TOC (**must match the cards**) → divider → 4–6 story cards → a utility/"playbook" segment that teaches something free → house blurb + CTA → sign-off → compliant footer.

## Each story card
Small all-caps category label → emoji + headline (a real `<a>` link) → image → "Image source:" caption → **The Short Version** (1 para) → **The Details** (4 UNIQUE bullets) → **Why It Matters** (1 para) → "Read more →".

## The native card (position 3) — the disguised ad
Styled BYTE-IDENTICAL to the news cards. Links to the shared Medium affiliate article. Content must MATCH the article (never invent). Fits the niche + the affiliate offer.

## Rules
- Mention budget: exactly **2** per issue (native card + bottom blurb).
- Banned words: game-changing, unlock, revolutionize, imagine if, supercharge.
- TOC must match the actual cards (no dangling references to swapped-out stories).
- Full detail: `NEWSLETTER-PLAYBOOK.md`.
