# Newsletter Send Schedule (target)

- **The Dealmaker** (direct flagship) — **3×/week** → Mon, Wed, Fri
- **The Referral Channel** (editorial flagship) — **2×/week** → Tue, Thu
- **Niche newsletters** — **5×/week TOTAL** (one per weekday, **rotating** through the niches — NOT 5× per niche). Later, as we scale, go per-niche.

- **Send times:** rotate/split-test (9:30am vs 1:30pm vs ~5pm) per Justin — same email, different times, compare opens/clicks.
